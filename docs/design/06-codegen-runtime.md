# sqletch Design — 06: Code Generation and Runtime (Phase P6)

Deliverable: `internal/codegen` + public `runtime/` package + the
generated-code contract. After this phase, `examples/` compiles and
runs end-to-end against the dev DB.

Prerequisites: P1–P5 (typed, rule-checked queries).

## 1. Generated package layout

Per config output target (one Go package):

```
gen/
  db.gen.go        DBTX, Queries, New, WithTx, OnQuery hook, ptr helper
  models.gen.go    (reserved; v0.1 emits row structs per-query file)
  <query>.sql.gen.go  per source file: params/row structs, enums, funcs
  querier.gen.go   Querier interface over all query methods
```

Every emitted name ends in `.gen.go` so generated files are
recognizable by name (glob-based tooling, review filters), not only by
the header. `codegen.Generate` returns them keyed by base name and a
test pins the suffix on every key.

All files carry `// Code generated by sqletch. DO NOT EDIT.` and are
gofmt'd via `go/format` before write; writes are atomic
(tmp+rename) and skipped when content is unchanged (mtime hygiene for
build systems).

## 2. `db.gen.go` (sqlc-compatible surface, pgx flavor)

```go
type DBTX interface {
    Exec(context.Context, string, ...any) (pgconn.CommandTag, error)
    Query(context.Context, string, ...any) (pgx.Rows, error)
    QueryRow(context.Context, string, ...any) pgx.Row
}
func New(db DBTX) *Queries
func (q *Queries) WithTx(tx pgx.Tx) *Queries
func (q *Queries) OnQuery(fn func(shapeKey, sql string)) // observability hook
func ptr[T any](v T) *T // exported as Ptr; examples alias it
```

`pgx.Tx` satisfies `DBTX` — one transaction serves sqlc- and
sqletch-generated code (spec: Generated API Conventions). The
composed-SQL cache is on `Queries` (shared via `WithTx` copies, guarded
by `sync.RWMutex`).

## 3. Per-query emission

For Use Case 1 the emitted shape (abridged; golden tests pin the full
text):

```go
type SearchUsersSort int
const (
    SearchUsersSortDefault SearchUsersSort = iota
    SearchUsersSortCreatedAtDesc
    // …
)

type SearchUsersParams struct { /* per R9: pointers for optional */ }
type SearchUsersRow struct    { /* per P5 nullability */ }

// fragment table: compile-time constants, never mutated
var searchUsersFrags = []runtime.Frag{
    {Text: "SELECT\n    u.id, …\nFROM users AS u", Kind: runtime.Skel},
    {Text: "JOIN organization_users AS ou\n  ON …", Kind: runtime.Guarded,
     Bit: 0, Sep: runtime.SepNone, Params: []int16{0}},
    {Text: "WHERE TRUE", Kind: runtime.Skel},
    {Text: "u.status = :status", Kind: runtime.Guarded, Bit: 1,
     Sep: runtime.SepAnd, Params: []int16{1}},
    // …
    {Kind: runtime.Choose, Block: 0, Cases: []runtime.Case{
        {Text: "ORDER BY u.created_at DESC"}, /* … */,
        {Text: "ORDER BY u.id ASC"}, // default = last
    }},
    {Text: "LIMIT :limit", Kind: runtime.Skel, Params: []int16{5}},
}

var searchUsersMeta = runtime.QueryMeta{
    Name: "SearchUsers", ParamTypes: []uint32{20, 25, 25, 1184, 20},
    // pinned OIDs, premise P1 — passed to pgx via QueryExecMode +
    // explicit type registration (see §5)
}

func (q *Queries) SearchUsers(ctx context.Context,
    arg SearchUsersParams) ([]SearchUsersRow, error) {
    key := runtime.ShapeKey{}
    if arg.OrganizationID != nil { key.Guards |= 1 << 0 }
    if arg.Status != nil        { key.Guards |= 1 << 1 }
    // …
    ord, err := runtime.ChooseOrdinal(int(arg.Sort), 4, true /*hasDefault*/)
    if err != nil { return nil, err } // zero-value-without-default error
    key.Choices = []uint8{ord}

    sql, argIdx := q.cache.Compose(searchUsersFrags, key) // §4
    args := runtime.Bind(argIdx, /* flattened arg values */)
    q.hook(key.String(), sql)
    rows, err := q.db.Query(ctx, sql, args...)
    // pgx.CollectRows into []SearchUsersRow …
}
```

Naming: `snake_case`→PascalCase; `@case` value → PascalCase suffix.
Post-mapping collisions (two params mapping to one Go name, enum
constant colliding with another decl) are `SQLETCH310` at generate
time — never silently renamed.

## 4. `runtime` composition (mirror of ast.Render)

```go
package runtime
type Frag struct{ Text string; Kind Kind; Bit int8; Sep Sep;
                 Params []int16; Block int8; Cases []Case }

func Compose(frags []Frag, key ShapeKey) (sql string, argIdx []int16)
```

Algorithm — the byte-for-byte mirror of `ast.Render` (00's shared
conformance test enforces equality):

1. Walk frags in order. Skeleton → emit. Guarded → emit iff
   `key.Guards` bit set, prefixed by its separator rendering
   (`SepAnd` → `"AND ("` … `")"`), joined by `"\n"`. Choose → emit
   `Cases[key.Choices[Block]]`.
2. Placeholder assignment: walk emitted frags' `Params` (template-param
   indices); first occurrence of param p ⇒ next `$n`; every occurrence
   rewrites to its assigned number. Fragment `Text` stores `:name`
   spans pre-tokenized at generate time (`ParamSpans []Span` in `Frag`,
   omitted above) so composition does zero SQL scanning at runtime.
3. Returns `argIdx`: for placeholder n, which params-struct field
   (flattened index) to bind — `Bind` dereferences pointers (guard
   active ⇒ non-nil by construction).

Composed `(sql, argIdx)` is cached per canonical `key.String()` in a
bounded cache (`statement_cache_size`, default 256 entries/query is
plenty: shapes-in-use are few). Key comparison on hit is full struct
equality, not the string hash.

Hits are lock-free: the entry map is published as an immutable snapshot
read through an atomic pointer, and only misses take the mutex. That
costs exact LRU ordering — a hit sets a second-chance bit on its own
entry rather than reordering a shared list, and eviction sweeps from
the oldest end granting one reprieve per set bit. The snapshot may lag
the authoritative map after an eviction, which is harmless (composition
is deterministic, so a stale entry is the same SQL) and bounds retained
entries at twice the capacity. Republishing copies the map, so it is
amortized once the shape set outgrows the capacity: a thrashing
workload falls back to the locked path instead of paying O(cap) per
miss.

`prepared` statement mode is **not** sqletch code: pgx's
`QueryExecModeCacheStatement` provides per-connection statement
caching keyed on SQL text (spec: delegate to the driver). Config maps
`statement_cache: text|prepared` to the pgx exec mode set on `Queries`.

## 5. Premise P1 in practice

Pinned types travel two routes:

- Bind side: generated code passes values as concrete Go types matched
  to the pinned OIDs (pgx encodes with the statement's OIDs from
  Parse/Describe in prepared mode; in text mode, pgx's type map +
  explicit casts are unnecessary because values are typed Go — the
  compile-time agreement check in 04 §5 guarantees no rendering
  disagrees).
- Scan side: `pgx.CollectRows` with field targets whose Go types came
  from the same OIDs.

The one sharp edge: text-mode `unknown`-typed placement (e.g. a param
used only as `$1 || '%'`) — already forced to a cast at compile time
by `SQLETCH201`, so runtime never re-litigates types. This is the
implementation content of "P1: per-shape re-inference never occurs".

## 6. `explain` data

Codegen also emits (into `.sqletch/explain/<query>.json`, not into the
Go package): guards with bits, choose blocks/cases, shape count, the
maximal SQL. `sqletch explain` (07) renders from these files — no
recompilation needed for the listing form.

## 7. Testing & acceptance criteria

- Golden generated-code tests for every corpus template (byte-exact,
  gofmt-stable).
- Compose conformance: for all corpus templates × all enumerated
  shapes (capped), `runtime.Compose` output == `ast.Render` output
  byte-for-byte (this is the load-bearing test of the whole design).
- Compose conformance, differential form: `FuzzComposeConformance`
  asserts the same equality over templates the authored corpus cannot
  reach, across all three profiles and both placeholder styles. Inputs
  that fail to scan are skipped, as are shapes the renderer refuses —
  it is the reference, so a shape it will not render has nothing to
  conform to. `@filter-tree` and `@in` are out of scope: they compose
  through `ComposeTree` and through an arity shape dimension, and have
  their own conformance tests; comparing them against plain `Compose`
  would be comparing against the wrong composer.
- Runtime unit: capacity bound under churn, concurrent hits under
  `-race`, full-key comparison on hit, ChooseOrdinal error on zero value
  without default, Bind pointer flattening.
- End-to-end (`-tags devdb`): `examples/` — generate, `go vet`+build,
  run Use Cases 1–3 against seeded data; `OnQuery` hook observes the
  composed SQL; double-generate produces zero diff.
- Acceptance: sqlc side-by-side smoke — a repo with both generators
  sharing one `pgx.Tx` compiles and passes a transfer-style test.
