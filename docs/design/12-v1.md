# sqletch Design — 12: the v1.0 stability audit

v1.0 per the spec: **stable template language and generated API;
comprehensive documentation; sqlc coexistence/migration guide.**
Breaking changes were free until the v1.0.0 tag and expensive after, so
every surface v1 pins was audited before the freeze. This doc is that
audit record: what was inspected, what was decided, and what had to be
fixed first.

The *promises* the audit produced are user-facing and live in the
manual: [`../manual/11-compatibility.md`](../manual/11-compatibility.md).
This doc is the reasoning behind them — read it when you need to know
*why* a surface was frozen in the shape it was, or when considering a
change that would touch one.

## Audited surfaces and verdicts

| Surface | Verdict |
| --- | --- |
| Template language (constructs, `-- name:` headers, `-- @param` / `-- @column`) | **Freeze as-is.** Construct vocabulary survived four development milestones without a rename; annotations are uniform across dialects. |
| Generated API (`New(DBTX)`, `Queries`, `WithTx`, `OnQuery`, `Querier`, params/rows structs, per-query enums/constructors) | **Freeze as-is.** Deliberately sqlc-shaped; both driver flavors (pgx, database/sql) mirror sqlc's, so coexistence stays trivial. **Amended before the v1.0.0 tag:** values the caller must not omit — policy-woven parameters and the tree of a `@filter-tree!` — are arguments of the generated method rather than params fields. Keeping them as fields made omission compile and send the zero value, i.e. a silently unscoped read; see 14 §D3 as amended. Everything else in this row is unchanged. |
| `runtime` package | **Freeze, with the contract written down** (package doc "API contract (v1)"): user API (Tree, caps, sentinel errors) vs generated-code contract (Frag/ShapeKey/…, public only because generated code lives outside the module; regenerate after upgrading sqletch). Considered splitting machinery into a subpackage; rejected — churn without a compatibility gain, and the doc contract covers it. |
| `sqletch.yaml` | **Freeze as-is.** Keys reviewed; naming consistent (`static_expansion`, `filter_tree_caps`, `database.dsn` with per-dialect meaning). Strict decoding already rejects unknown keys. |
| CLI (`generate` / `check [--exhaustive]` / `explain [--enumerate\|--analyze]` / `fmt [--check]` / `lsp` / `version`, `--config`, `--json`, exit codes 0/1/2) | **Freeze as-is**; exit codes documented in the manual. |
| Diagnostics | **Freeze code MEANINGS, not message text.** No collisions across the code space. The manual carries a reference table, with `diagnostics.TestManualCoversAllCodes` asserting every constant is documented and no documented code has been removed (drift-proof in both directions). |
| Committed cache format | **Fixed pre-freeze**: files carry `"format": 1` (`cache.FormatVersion`); any other value — including its absence in pre-1.0 caches — loads as a miss, so format evolution can never misread an old entry, it just re-describes. One-time invalidation of pre-1.0 caches (examples cache regenerated). |
| Go module versioning | Single module `github.com/moznion/go-sqletch`; tag `v1.0.0` keeps import paths stable. `sqletch version` exists for release identification. |

## Consequences for later work

- Adding a construct or a slot is compatible; **renaming or
  re-scoping one is not** — it breaks templates that already compile.
- Adding a field to a params/row struct is compatible; reordering or
  retyping is not.
- Adding a diagnostic code is compatible (and requires a manual row, or
  the coverage test fails). Reusing a retired code number is not.
- Changing anything that alters generated bytes for unchanged inputs
  needs a deliberate decision: determinism is an invariant, and
  byte-pinned outputs (cache JSON, `--json`, LSP frames) have tests
  that will catch it. Changing the cache's on-disk shape means bumping
  `cache.FormatVersion`, which is by design a cheap, safe operation —
  old entries become misses.
- Splitting `runtime` machinery out of the public package remains
  possible only across a major version, per the verdict above.
